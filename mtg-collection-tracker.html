Bulk Import

One entry per line, either format, mixed freely:
CSV: Card Name,Set Code,Quantity,Condition,Treatment,Price Paid — only the name is required; leave the rest blank for defaults (qty 1, Near Mint, Normal, no price paid). Treatment must be one of normal, foil, etched, showcase, borderless, prerelease, planeswalkerstamp. Price Paid is per card, not per line total.
Plain decklist line: 4 Lightning Bolt — just quantity and name, everything else defaults.
Blank lines and lines starting with # are skipped, and a header row starting with "name" is detected and skipped automatically. Cards priced as Normal or Foil are looked up in one fast batch; Showcase, Borderless, Prerelease, Foil-Etched, and Planeswalker Stamp rows are looked up one at a time (same specific-print search used by the single Add form), so very large imports with lots of special treatments will take a bit longer. As always, this needs to be running as its own hosted page, not Claude's preview pane, for the lookups to work.

Look Up Card Popularity

"Popularity" here is each card's EDHREC rank (lower = more played) — the best free, live-queryable proxy available. It reflects Commander deckbuilding popularity, not eBay sales volume or competitive Standard play rate, since neither eBay's sold-listing data nor Standard metagame share is available through any free public API right now.

For how a card is actually performing in Standard tournaments, check MTGGoldfish directly — they track real tournament results but don't publish an API, so this links out rather than guessing at their numbers:

Same mechanics as the Standard leaderboard above, but pulling the 40 Commander-legal cards with the best EDHREC rank — this one's a more direct read, since EDHREC rank is a Commander metric natively rather than a proxy borrowed from another format.

On the "refresh every day at 3am" idea: this is a plain HTML file with no server, so it genuinely cannot run anything while the page/browser is closed — there's no such thing as a static webpage waking itself up at 3am. What it does do: each time this page loads, it checks whether today (using a 3am boundary, so "today" starts at 3am and runs until 3am the next day) already has a recorded snapshot; if not, it silently fetches one automatically, for both leaderboards. So in practice, if you keep a browser tab on this page (or just open it once each morning), it records one snapshot per day on its own, and keeps up to the last 30 recorded days in this browser's storage. If you want true background automation — running even with no tab open, e.g. via a scheduled job — that needs real server infrastructure (like a small scheduled script that writes to a shared file or database), which is a bigger build than a single HTML file; happy to help with that if it turns out to matter to you.

Recent Tournament Results

This tab pulls real recent tournament results and decklists from TopDeck.gg's free tournament API, routed through corsproxy.io since TopDeck.gg doesn't allow direct browser requests — so your API key does pass through that relay, not just TopDeck.gg. Get a free key at topdeck.gg/developers and paste it above — it's saved only in this browser's local storage. Per their terms, this credit is required: Data provided by TopDeck.gg. Card prices for each decklist are looked up live from Scryfall when you click "View decklist & prices," so nothing is priced until you ask for it.

TopDeck.gg's API itself only supports "days back from today," not picking specific dates, so adding date(s) above fetches a wide-enough window under the hood and then filters down to just the day(s) you picked, here in the browser. Tournament dates are compared using your browser's local timezone against TopDeck.gg's recorded start time, so an event right around midnight could occasionally land on the adjacent day.

Track Booster Boxes & Packs

This tab uses TCG API (tcgapi.dev), a third-party service built after TCGPlayer closed public API access to new developers, routed through corsproxy.io since TCG API doesn't allow direct browser requests either — so your API key passes through that relay too, not just TCG API. Get a free key at tcgapi.dev/signup (no card required, 100 requests/day free). It's saved only in this browser's local storage. This is a newer, unofficial service, not TCGPlayer or Wizards themselves. One thing not fully confirmed: searches assume Magic's game slug is magic — if searches keep coming up empty, open api.tcgapi.dev/v1/games directly in your browser (no key needed) and check the exact slug listed for Magic: The Gathering, then let us know if it's different.

To browse several matches before picking one, use the search box above and click "Track" on the one you want instead.
